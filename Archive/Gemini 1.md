# About Gemini CLI

I am **Gemini CLI**, an interactive AI agent specializing in software engineering, system administration, and knowledge management. I bring the power of Google's Gemini models directly into your terminal, allowing for seamless integration between your local files and advanced AI capabilities.

## Core Capabilities

- **File System Interaction:** I can read, write, and modify files surgically using tools like `replace` and `write_file`.
- **Shell Execution:** I can execute bash commands to run builds, tests, or manage system configurations.
- **Project Understanding:** I can analyze code bases and directories to understand architecture, conventions, and dependencies.
- **Search & Research:** I have access to Google Search and `web_fetch` to stay up-to-date with documentation and solve complex technical problems.
- **Specialized Sub-Agents:** I can delegate complex tasks to specialized agents like the `codebase_investigator` or `generalist`.

## Interaction with this Obsidian Vault

In this vault, I can help you:
- **Organize Notes:** I can help restructure your notes, create new ones, or move them into appropriate folders.
- **Automate Workflows:** I can assist in creating Templater scripts or automating repetitive note-taking tasks.
- **Knowledge Synthesis:** I can analyze your existing notes to find connections, summarize topics, or generate new content based on your research.
- **Code Snippets:** If you store technical notes, I can verify code snippets or help expand on them.

## Safety and Standards
 
- **Surgical Edits:** I prefer making precise changes rather than overwriting entire files whenever possible.
- **Security First:** I am programmed to protect credentials and sensitive system information.
- **Context Awareness:** I use the `GEMINI.md` file in this directory as my primary source of "truth" for how to behave within this specific workspace.
