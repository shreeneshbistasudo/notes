# Gemini CLI - Workspace Context

This directory is an **Obsidian Vault** used for personal knowledge management, documentation, and notes.

## Directory Overview

*   **Type:** Personal Knowledge Base / Obsidian Vault.
*   **Structure:**
    *   `.obsidian/`: Contains vault-specific settings, enabled plugins, and themes.
    *   `GEMINI.md`: This configuration file providing context for AI interactions.
    *   `Gemini.md`: A secondary/duplicate context file (currently empty).

## Obsidian Configuration

*   **Theme:** The vault uses the **Catppuccin** community theme.
*   **Key Plugins:**
    *   **Templater:** For advanced Markdown templating.
    *   **Daily Notes:** (Core) For chronological journaling.
    *   **Templates:** (Core) For standard reusable note structures.
    *   **Sync:** (Core) Enabled for cross-device synchronization.

## Interaction Guidelines

When interacting with this workspace, please adhere to the following conventions:

1.  **Markdown Format:** All notes should be written in standard Markdown.
2.  **WikiLinks:** Use `[[Link Name]]` for internal cross-references, as per Obsidian defaults.
3.  **Frontmatter:** Use YAML frontmatter for metadata if required by plugins like Templater or for organization.
4.  **No Codebase:** This is a non-code project; avoid searching for build scripts or source code unless they are explicitly part of a note or snippet.
